# PlanSeed v0.2 — Architect Workflow

> **状态：** In Progress（2026-11-21）  
> **前置：** v0.1.1-alpha Released · Solver 0.6 · Release Qualification ✅  
> **目标：** 从「能生成住宅平面」升级为「建筑师可持续参与的设计工作台」  
> **产品主线提升：** Design Intent Patch + Topology Strategy + 受控优化闭环（AI Design Copilot）；KPI = **ab_rate**

## 产品转变

```text
过去：Requirement → Solver → Floor Plan（一次性生成器）

未来：
                  ┌──────── Architect ────────┐
                  │                           │
Intent → Topology → Solver → Evaluate → Plan │
                  ↑                    ↓      │
                  └──── Mutate ← Compare ←───┘
```

**核心指标转变：**

| 旧 | 新 |
|----|-----|
| `top_score` 88.2 → 89.4 | **A/B 级候选出现率**（`ab_rate`） |
| `valid_rate` gate | Architect acceptance gate |
| Generator qualification | Design tool iteration |

### 执行顺序（纪律 · 2026-11 重排）

```text
Benchmark v2 + Partial Regen 地基
    ↓
DesignIntentPatch（AI-1）
    ↓
TopologyStrategy（AI-2，非完整 Bubble UI）
    ↓
DesignCritic + OptimizationSession（AI-3）
    ↓
DesignConversation Copilot（AI-4）
    ↓
Topology Workbench UI / Revision Tree UI / CAD（并行延后）
```

**禁止：** 没有 Intent Patch + Partial Regen，Copilot 只能重写 RequirementSpec 整栋重生成。  
**禁止：** `preserve_topology` 未硬化前开放无人值守自动优化。

## 各阶段摘要

### 0.2-A — Design Benchmark v2（P0）

- **文档：** [design-benchmark-v2.md](design-benchmark-v2.md)
- **交付：** B01–B20 case 定义 · `ab_rate` 指标 · 评级工作流 · harness 代码
- **首跑：** Core cases B01–B07，Guillotine only

### 0.2-B — Partial Regeneration（P0 · 部分完成）

- **已交付：** `RegenerationScope`、locks 推导、`POST /api/regenerate/partial`、Desktop 局部重生成
- **已硬化：** `preserve_topology` — 锁定↔锁定 RoomGraph 邻接 / required Access 在 regen 后必须保留，否则 422
- **仍可加强：** affected_neighbors 自动扩 mutable、regen 专用 ab_rate case

### AI-1 / 0.2-F — Design Intent Patch（P0）

- **目标：** 针对当前方案的 NL → `DesignIntentPatch` → program/constraint 增量 → `RegenerationScope`
- **非目标：** LLM 直接输出坐标或重写完整 RequirementSpec
- **入口：** `packages/schema/intent_patch.py` · `packages/llm/intent_parser.py` · `/api/copilot/intent/*`

### AI-2 — Topology Strategy（P0）

- **目标：** 2–3 套命名策略 → `RoomGraph` delta → `TopologyPlanner`（非 Bubble 编辑器）
- **入口：** `packages/schema/topology_strategy.py` · `solver/topology/strategy.py` · `/api/copilot/strategies`

### AI-3 — Critic + OptimizationSession（P1）

- **Critic：** 只读 Gate / Findings / metrics → 建议 IntentPatch
- **Session：** 有限轮次局部 regen + 停止条件（无改善×2 / 预算 / 拓扑破坏）

### AI-4 / 0.2-G — Design Conversation（P1）

- **目标：** 多轮对话上下文（选中候选、策略、补丁）+ Desktop 设计助手面板
- **原则：** AI understands intent · Solver proves geometry

### 0.2-C — Topology Workbench UI（P1 · 延后）

- Bubble / adjacency graph 可视化编辑；策略层已先落地

### 0.2-D — Site Editor 2.0（P1）

- Import/Draw → 退界 → 北向 → buildable preview；产品默认仍 rect

### 0.2-E — Revision Tree UI（P1 · 延后）

- 树形导航；`variant_parent_id` / mutations 字段已有

### 0.2-H — CAD / DXF Interop（P2）

- 进入建筑师现有工作流（导出/导入）

# PlanSeed v0.2 — Architect Workflow

> **状态：** Planning（2026-08-26）  
> **前置：** v0.1.1-alpha Released · Solver 0.6 · Release Qualification ✅  
> **目标：** 从「能生成住宅平面」升级为「建筑师可持续参与的设计工作台」

## 产品转变

```text
过去：Requirement → Solver → Floor Plan（一次性生成器）

未来：
                  ┌──────── Architect ────────┐
                  │                           │
Intent → Topology → Solver → Evaluate → Plan │
                  ↑                    ↓      │
                  └──── Mutate ← Compare ←───┘
```

**核心指标转变：**

| 旧 | 新 |
|----|-----|
| `top_score` 88.2 → 89.4 | **A/B 级候选出现率**（`ab_rate`） |
| `valid_rate` gate | Architect acceptance gate |
| Generator qualification | Design tool iteration |

```text
Benchmark v2
    ↓
Partial Regeneration（RegenerationScope）
    ↓

    ↓

    ↓
```

**禁止跳序：** 没有 Intent Patch + Partial Regen，Copilot 只能重写 RequirementSpec 整栋重生成。

## 各阶段摘要

### 0.2-A — Design Benchmark v2（P0）

- **文档：** [design-benchmark-v2.md](design-benchmark-v2.md)
- **交付：** B01–B20 case 定义 · `ab_rate` 指标 · 评级工作流 · harness 代码
- **首跑：** Core cases B01–B07，Guillotine only

### 0.2-B — Partial Regeneration（P0）

- **目标：** `RegenerationScope` → 锁定满意部分 → 局部重生成
- **现有基础：** `LayoutLocks` + 整层 Guillotine 重跑
- **缺口：** `mutable_rooms` / `affected_neighbors` / `preserve_topology` 抽象

```python
# 目标 schema（草案）
RegenerationScope(
    mutable_rooms=[...],
    locked_rooms=[...],
    affected_neighbors=[...],
    preserve_topology=True,
    preserve_floor_assignment=True,
)
```

### 0.2-C — Topology Workbench（P1）

- **目标：** Bubble / adjacency graph 编辑 → Solver
- **现有基础：** `TopologyPlan` / `RoomGraph` / `AccessGraph` 已驱动 Guillotine
- **缺口：** 用户可编辑 graph UI + 持久化 + lock topology → regen geometry

### 0.2-D — Site Editor 2.0（P1）

- **目标：** Import/Draw → 编辑边界 → 退界 → 北向 → buildable preview → Generate
- **现有基础：** `site_polygon` / Shapely pipeline（engineering only）
- **缺口：** Desktop Site Editor；产品默认仍 rect

### 0.2-E — Revision Tree（P1）

- **目标：** 方案谱系 A → A1 → A1a 树形导航与比较
- **现有基础：** flat `variant_parent_id` + `revision_status` + `mutations[]`
- **缺口：** 树形数据模型 + UI panel

### 0.2-F — Design Intent Patch（P2）

- **目标：** 自然语言 → 结构化意图补丁 → constraint/objective 增量
- **非目标：** LLM 直接输出坐标或重写完整 RequirementSpec

### 0.2-G — Local AI Design Copilot（P2）

- **依赖：** 0.2-F Intent Patch + 0.2-B Partial Regen
- **原则：** AI understands intent · Solver proves geometry

### 0.2-H — CAD / DXF Interop（P2）

- **目标：** 进入建筑师现有工作流（导出/导入）

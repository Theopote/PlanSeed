## PlanSeed Alpha v0.1.1 (build 2)

**Platform:** Windows 10/11 x64 only · solver 0.6

### Install
1. Download `PlanSeed_0.1.1_x64-setup.exe`
2. Run the installer
3. Launch **PlanSeed** and wait until the engine shows Ready

### What's new
- **Settings panel** — configure Ollama URL / model / timeout from the UI (saved to `~/.planseed/settings.json`)
- Partial regeneration scope fixes
- Release smoke test extensions

### Notes
- Local-first desktop app (Tauri + embedded solver engine)
- Natural-language parsing needs a local [Ollama](https://ollama.com) install (optional; configurable in Settings)
- This is an **Alpha** build for early testing

See: `docs/alpha-v0.1.1-release-notes.md`
